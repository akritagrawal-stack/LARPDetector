LARP Detector Browser Companion

Select the browser-extension folder opened in Finder. The companion shares only the active linkedin.com/in/... URL with the local LARP Detector app.

Chrome, Comet, Brave, Edge, Arc, or Chromium

  1. Open chrome://extensions.
  2. Enable Developer mode.
  3. Choose Load unpacked and select the opened folder.

Safari

Safari does not use this unpacked extension. Open a LinkedIn profile in Safari and trigger a scan, then approve the macOS Automation prompt. You can also paste the complete profile URL into LARP Detector.

After installation, open a LinkedIn profile. LARP Detector Settings will show Connected.
